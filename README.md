# Bike Sharing Data Analysis Dashboard

## Deskripsi Project
Project ini merupakan analisis data Bike Sharing Dataset menggunakan Python dan Streamlit.

Analisis dilakukan untuk mengetahui:
- Pengaruh kondisi cuaca terhadap jumlah penyewaan sepeda
- Jam dengan jumlah penyewaan tertinggi

## Struktur Folder

```text
submission/
├── dashboard/
│   ├── dashboard.py
│   └── main_data.csv
├── data/
│   ├── day.csv
│   └── hour.csv
├── notebook.ipynb
├── README.md
├── requirements.txt
└── url.txt
```

## Cara Menjalankan Dashboard

### 1. Install Library

```bash
pip install -r requirements.txt
```

### 2. Jalankan Streamlit

```bash
streamlit run dashboard/dashboard.py
```
